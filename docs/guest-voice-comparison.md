# ゲスト二声比較の境界

ゲストは任意で、最初と二回目の発話冒頭を一度だけ聞き比べられます。これは声紋認証や話者識別ではなく、本人が自分の変化を耳で確かめるための短い再生機能です。

## 所有と上限

- 初期値は無効です。利用者がチェックした場合だけ開始します。
- 通常の音声送信用フレームとは別の `ArrayBuffer` を端末内で所有します。
- 16 kHz・PCM16・20 msのフレームを各50個まで、二回分だけ保持します。最大値は64,000 byteです。
- 同じセッションgeneration以外のフレームは受け取らず、受け取った不正な所有コピーもゼロで上書きします。
- 特徴量、声紋、文字起こし、利用者IDは作りません。比較用PCMをHTTP、WebSocket、ログ、Storage、IndexedDBへ追加送信しません。

## 再生を許す条件

二回の発話が揃い、サーバーの有限なA-first証明が `changed_to_answer_first` を返した場合だけ再生可能にします。`stayed_answer_first`、証明なし、中断、異なるgeneration、空の発話では全コピーを消去します。再生可能イベントには内容を載せず、固定versionだけを渡します。

## 消去

再生へ所有権を移した直後にPCMの各バイトをゼロで上書きします。再生終了後はWeb AudioのFloat32チャンネルもゼロで上書きします。「聞かずに消す」、セッション終了、`pagehide`、例外、所有境界違反でも同じ消去処理を実行します。

JavaScriptとWeb Audioの内部コピーやブラウザ実装の物理メモリまで、アプリケーションから完全消去を証明することはできません。そのため永続化しないこと、保持時間と容量を有限にすること、利用者が明示的に開始・消去できることを保証境界とします。
